# Public data included in this repository

`data/processed_pairs/` contains compact composition-level tables used by the software examples and tests.

`data/source_small/` contains selected public processed metadata needed by dataset adapters. Large original single-cell matrices and raw sequencing files are not redistributed.

`data/pending/` documents a pre-specified cohort geometry for which the required outcome-independent cell-state labels were not available in the archived material. No score is generated from missing labels.
